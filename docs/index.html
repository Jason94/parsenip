Source :S :C :TMethods:
  • INITIAL-CURSOR :: :S → :C
    Cursor pointing to the beginning of `source`.
  • ADVANCE-N :: :S * :C * UFix → Optional :C
    Attempt to advance `cursor` by `n`. Returns `None` if EOF.
  • CURSE :: :S * :C → Optional :T
    Attempt to get the value at `cursor` in `source`. Returns `None` if EOF.
  • STEP :: :S * :C → Optional (Tuple :T :C)
    Attempt to lookup the value at `cursor` and advance the cursor by 1. Returns `None` if EOF.
  • RECLAIM! :: :S * :C → Void
    Signal that the parser will never backtrack before `cursor`. Is allowed to mutate the source, such that any curses to `cursor` or later will not be affected. Allows reclamation of memory for unbounded sources.
